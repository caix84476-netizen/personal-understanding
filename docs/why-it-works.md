# 设计动机：为什么做成这样

> 本文回答 README 里所有的「为什么」。三个问题：它反对什么（第一节）、它信奉什么（第二节）、它的每条规矩是从哪来的（第三节）。所有事故都能在 [CHANGELOG.md](../CHANGELOG.md) 里对号；机制实现见 [docs/how-it-works.md](how-it-works.md)。

## 1. 它反对什么：主流记忆工具的三个原罪

市面上 AI 记忆工具的共同姿势是：**每句话先进 embedding、先摘要，原话加工完就丢**。这带来三个结构性后果：

1. **不可审计**——半年后它把你记错了，你手里没有原话可核对，只剩一句不知经过几道加工的摘要。
2. **不确定就编**——检索没命中时，向量库里总有「语义上差不多」的东西垫着，模型拿它编出一个看起来合理的答案。
3. **纠正无门**——你说「我当时不是这么说的」，系统没法改：「你当时说的」根本不存在了。

这个项目的回答是把顺序倒过来：**先一字不改存原话，理解是原话的派生物**——派生物可以随时重算、作废、纠正，原话永远在位（[保真机制](how-it-works.md)）。

## 2. 它信奉什么：六条设计哲学

### 2.1 原话优先

先存原话，再派生理解。纠正只新增、不静默改；模型摘要不得冒充原话；丢了来源的旧摘要诚实标 `summary_only`。审计的终点永远是你自己说过的话，不是模型说过的话。（[references/capture-and-verbatim-policy.md](../references/capture-and-verbatim-policy.md)）

### 2.2 派生闭环

「存下了」不等于「档案更新完了」。每条捕获必须走完派生并显式闭环，孤立捕获过不了回答前的硬闸门。这不是仪式感——是 2.5.0 那次「写成功也报错、客户端重试、重复建档」事故之后立下的规矩（[事故表](#31-事故与修补全表)）。

### 2.3 诚实边界

不确定就说不知道；禁止宣布「查不到」，也禁止编一个补上。模型的成因猜测进独立假设层、恒为 `candidate`，永不悄悄转正。事实、评价、解释、假设、无法确认五层分开摆。「档案里没有 X」是要有 probe 证据才能出口的断言。（[references/causal-hypothesis-policy.md](../references/causal-hypothesis-policy.md)、[retrieval-policy.md](../references/retrieval-policy.md)）

### 2.4 时间主干

每条记录带发生日/精度/依据/阶段/前后邻居，事件发生日、回忆日、录入日分开——禁止把录入当天冒充发生日。任何「你现在处于某阶段」的断言，先对日期再讲故事。（[references/timeline-and-followup-policy.md](../references/timeline-and-followup-policy.md)）

### 2.5 召回体力活归工具，判断归模型

不把全库灌给模型，也不让工具替模型下结论：survey 给地图、probe 给候选、deep 给原话、联想通道给「可能相关你看着办」。工具宁滥勿漏，模型必须自己提关键词、自己判断联想成不成立、自己向用户说明为什么某条噪声不采信。（[references/retrieval-policy.md](../references/retrieval-policy.md)）

### 2.6 本地可审计

一个文件夹、纯文本、可 grep、可 git diff；无遥测、无云调用、无第三方 embedding 服务；仅 Python 标准库——服务端逻辑谁都能读完。检索轨迹、派生台账、反馈记录全部落盘可回放。`.gitignore` 默认挡住 `memory/`、`sources/`、`backups/`。

## 3. 它从哪来：一个天天在用的档案磨出来的

这个系统不是设计出来的框架，是一份**天天在用的真实个人档案**被十几轮实测加固磨出来的。每条「奇怪」的规矩背后都有事故现场。

### 3.2 防过拟合三律

所有修复遵守三条纪律：

1. **修复常量不对单条查询调**——门控、迭代数、衰减周期、降权系数都按批次行为定；
2. **冻结的回归套件只作地板**，不作优化目标；
3. **每轮验收换全新试卷**（t10–t16 全部是上一轮没见过的题）。

一个只对验收题好用的记忆系统，不如没有。

## 4. 借鉴与致谢

检索与词面层的几个关键件站在前人工作上。2026-09-05 有一轮专门的「具体问题具体分析地借鉴前人」（commit `4c6f460`），每个借鉴都先测后取：

- **SYNAPSE**（ACL 2026 Findings）——sigmoid 门控 `σ(γ(s−θ)), γ=5, θ=0.5` 与 fan-effect 出度稀释，用于联想通道的邻居扩散激活门控；其激活级时间衰减方案经实测在本架构结构性无效，否决留档。
- **HippoRAG**（OSU/UCLA，NeurIPS 2024）——个性化 PageRank 的非均匀 reset 向量（查询命中强度驱动种子权重）与 damping 0.5；其收敛式 PPR 与现状局部扩散实测重合 0.64 但无增益，维持局部扩散。
- **Generative Agents**（Stanford）——词面通道时间衰减 `0.5^(age/180d)`；按本项目实测补了一条：缺日期记录中性 1.0。
- **Qiao & Sun**（ACL Y09-2003）——自训练领域词典对抗 web 语料 OOV：本项目档案自训练词表的源头。
- **jieba**（fxsjy/jieba，MIT）——中文分词词典，`resources/lexicon/jieba-dict.txt` vendor 自其 34.9 万词条。
