# Personal Understanding v2 Dashboard

Run `open-dashboard.cmd`. The dashboard is read-only, runs locally, and is not a second database.

## Pages

- Overview: event spine, current state, follow-ups, and fidelity;
- Timeline: a single 0–3 memory-weight axis;
- Entities: people, schools, places, objects, works, games, concepts, and environments;
- Context cards: cross-entity shared stories, e.g. school × football;
- Causal hypotheses: candidate explanations and their evidence boundaries;
- Follow-ups: questions that are due or still missing a due date;
- Sources: verbatim captures, legacy summaries, images, OCR, external material;
- Files: read-only browsing of the skill directory.

Legacy summaries are clearly labeled as `Legacy summary` and never passed off as verbatim. When the dashboard finds risks it shows warnings/failed instead of only showing "clean".
