# 2.0.0 v2 structure migration

Date: 2026-08-22

## Purpose

Upgrade from "record summaries + model retrieval" to "verbatim-first + timeline spine + entity network + context cards + proactive follow-ups + candidate causal explanations".

## Compatibility strategy

- `memory/records/` is not deleted;
- `sources/` is never rewritten;
- legacy record bodies generate `summary_only` fragments;
- records whose current-conversation source can no longer be re-read are listed as summary debt;
- v2 derived files are reproducibly generated by `rebuild_views.py`;
- `work/personal-understanding-v0.6.0-backup/` is the pre-migration rollback copy.

## Migrated content

- 203 legacy records → 118 timeline entries;
- 22 existing entities → v2 entity catalog;
- legacy relations → v2 relations;
- legacy open loops → v2 followups;
- current models/state/decisions → current-state snapshot;
- two verbatim captures from the 2026-08-22 session added as `verbatim` fragments.

## Not recoverable

Legacy records heavily used `current-conversation`, but no session transcript files exist. After scanning the available sources, legacy summaries cannot be reliably reverse-engineered into verbatim text, so that content remains `summary_only`. From now on, any personal-understanding addition must go through the capture chain.

```text
python scripts/rebuild_views.py

```

## Rollback

Stop using the v2 entry points and restore the files from `work/personal-understanding-v0.6.0-backup/`; the v2 derived directory never modifies legacy records or raw sources.
