# v2 Self-Distillation Policy

Effective chain:

```text
verbatim → timeline entry → entity/context network → current state / follow-ups → application → outcome → review
```

current state leads with the core, situation, experience, tensions, and next checkpoint; the timeline spine leads with the facts of what happened; entity profiles lead with social connections; only the hypothesis layer discusses why something formed.

Never replace events with a one-line personality label, and never pass off an event list as understanding. Every high-level conclusion must resolve back to events, verbatim, counterexamples, and time ranges.
