# Local Skill Regression Acceptance

1. User additions first produce an immutable verbatim capture;
2. The same capture cannot be overwritten; any hash mismatch must fail;
3. Derived records must resolve back to a capture or be explicitly marked as legacy summary-only;
4. Timeline entries have a single salience axis;
5. Events extend to people, places, schools, objects, works, concepts, and environments;
6. A cross-entity facet can be reached from any of its entities back to the shared story;
7. Due follow-ups get checked and are surfaced with context;
8. Contradictions surface the old claim, the new claim, dates, sources, and gaps;
9. Causal hypotheses default to candidate and must have mechanism, support, limits, and alternatives;
10. Validation reports clean / warnings / failed instead of always claiming pass;
11. Deep review can point out missing verbatim, date gaps, orphaned entities, unresolved relations, and summary debt;
12. The dashboard can view the timeline spine, entities, facets, hypotheses, follow-ups, and verbatim;
13. Legacy records and legacy views remain readable, and failed migration can roll back;
14. Unrelated tasks never pour unrelated private content into answers.
